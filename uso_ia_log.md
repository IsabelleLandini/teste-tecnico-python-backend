# Histórico de Uso de IA

## 1. Estrutura do projeto
IA sugeriu uma arquitetura em camadas:
- main.py
- services.py
- crud.py
- schemas.py
- database.py

* Segui essa arquitetura com pequenas adaptações para manter simplicidade do teste técnico.

## 2. Lógica de diagnóstico de produtividade
IA ajudou a refinar a regra de feedback baseada na média de foco.

* Refinei a mensagem para ficar mais natural e coerente com a experiência do usuário.

## 3. Testes
IA auxiliou na criação dos testes com TestClient.

* Adicionei setup com fixture para garantir isolamento entre os testes e limpeza do banco de dados.

## 4. Debug de erros durante desenvolvimento

A IA foi usada como apoio na resolução de problemas técnicos, incluindo:

- erro de importação do módulo `app`
- conflito de repositório Git dentro de outro repositório
- inconsistências em response_model
- testes com retorno inesperados (200 vs 404)

* Todos os erros foram entendidos e corrigidos manualmente após análise e validação.

## 5. Como a IA foi utilizada no desenvolvimento

A IA foi utilizada como ferramenta de apoio ao longo do desenvolvimento para:

- acelerar decisões de arquitetura
- explicar conceitos técnicos
- sugerir melhorias de código
- auxiliar na escrita de testes
- revisar estrutura geral do projeto

* Todas as decisões finais foram validadas, compreendidas e ajustadas manualmente.
